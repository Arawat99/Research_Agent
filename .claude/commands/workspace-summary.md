---
description: Summarize the project structure, size, and likely next steps.
---

Run the workspace summary script to inspect the repository and then give a concise operational summary.

Use:

```bash
python3 scripts/workspace_summary.py
```

Then report:

- total files and directories
- the main file types present
- the largest files or notable hotspots
- a brief assessment of project health
- 3 practical next steps for improving organization or clarity

If there are obvious gaps or risks, mention them clearly.
