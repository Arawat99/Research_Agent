---
description: Turn rough notes into prioritized action items.
---

Review the provided notes or note directory and convert the raw ideas into a practical action list.

Goal:

- extract concrete tasks
- group related ideas
- rank priorities
- identify obvious next actions

Format the result as:

- action item
- priority label (High / Medium / Low)
- brief reason or context
- optional next step

If the notes are vague, infer the most sensible actions while staying honest about uncertainty.

If no source is provided, look in the notes folder and pull the most relevant material.
