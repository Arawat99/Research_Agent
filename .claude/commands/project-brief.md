---
description: Create a short, professional project brief from a folder or active workstream.
---

Create a brief, business-friendly summary of the project or directory in context.

Use this structure:

1. Goal
2. Current status
3. Key risks or blockers
4. Immediate next steps
5. Recommendation

Guidelines:

- Keep it concise and readable.
- Prefer plain-language summaries over technical detail unless necessary.
- If no folder is specified, default to the current project or the most relevant active directory.
- Include a short action-oriented conclusion.

Output should be polished enough to share with a teammate or stakeholder.
